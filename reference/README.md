## On versions

NIST now ships SP 800-53 as patch releases against Revision 5 rather than a new
revision number. **Release 5.2.0** (27 August 2025) is the current one; it adds
controls for software update and patch integrity in response to Executive Order
14306, and revises the discussion text on some existing controls with extra
scoping and implementation examples.

The copy here is the earlier Revision 5 export. It's the one the course supplies
and it's fine for learning the structure, but anything I produce as a deliverable
should cite the current release. Latest versions come from the NIST Cybersecurity
and Privacy Reference Tool (CPRT), which publishes the catalogue as spreadsheet,
JSON and OSCAL.
