# Deliverables

Finished artefacts from the practical assessments, case studies and capstone —
the work worth showing. Grouped by engagement; file names keep the
`<module>-<artefact>` convention so links stay stable.

**Status key** — *My answer*: written before the course solution, no solution
received yet. *Compared with solution*: my answer as submitted, followed by a
comparison recording where I agreed, where I didn't, and what I missed.
*Complete*: a case study answered against a real document. *Self-directed*: work
I chose to do beyond the course.
