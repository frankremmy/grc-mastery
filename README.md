# GRC Mastery — Learning Log

Working notes and hands-on deliverables from the **Cyber Security Governance, Risk
and Compliance (GRC) Mastery** course, plus the ISO 27001 Lead Auditor track.

I'm a Support Engineer moving into security operations, and GRC is the half of the
job that doesn't show up in a CTF writeup. This repo is where the risk registers,
audit programs and control designs live so the work is visible rather than sitting
in a notes app.

Longer write-ups go on [frankremmy.com](https://frankremmy.com); this repo holds
the artefacts.
